# گروه صنعتی البرز — وب‌سایت

سایت استاتیک چندصفحه‌ای (HTML/CSS/JS ساده، بدون نیاز به build) برای گروه صنعتی البرز
و سه شاخه‌ی آن: چوب، فلز و سرمایه‌گذاری.

## ساختار پروژه

```
index.html            صفحه‌ی اصلی گروه (معرفی سه شاخه + تاریخچه + تماس)
woodwork/index.html    البرز چوب (کابینت البرز)
metalwork/index.html   البرز فلز (درب و پنجره)
investment/index.html  البرز سرمایه‌گذاری
css/style.css           استایل مشترک همه‌ی صفحات
js/script.js            منطق مشترک: منو، اسکرول نرم، گالری، لایت‌باکس
images/                 تمام عکس‌ها و لوگو
```

هر سه شاخه از همان هدر، فوتر، فونت و پالت رنگی گروه استفاده می‌کنند — فقط محتوا و
آیکون‌ها فرق دارد. جابه‌جایی بین شاخه‌ها از طریق دکمه‌های بالای صفحه ("چوب"، "فلز"،
"سرمایه‌گذاری"، "خانه گروه") انجام می‌شود.

## اطلاعات تماس

فایل `js/script.js`، بالای فایل:

```js
const SITE = {
  phone: '0917 768 4838',
  phoneHref: 'tel:+989177684838',
  instagram: 'alborz.titanium1',
  whatsapp: null
};
```

این مقدار در همه‌ی صفحات (گروه، چوب، فلز، سرمایه‌گذاری) یکسان استفاده می‌شود، چون
شماره‌ی جداگانه‌ای برای هر شاخه نداریم. دفتر استانبول (برای همه‌ی صفحات) مستقیم در
HTML هر صفحه نوشته شده: `+90 534 767 688`.

  کشور دارد؛ موبایل‌های ترکیه معمولاً ۱۰ رقم‌اند (5XX XXX XX XX). ممکن است یک رقم جا
  افتاده باشد.
- [ ] **آدرس اینستاگرام را چک کنید.** `@alborz.titanium1` الان روی صفحه‌ی چوب (کابینت

  اگر واقعاً برای فلز است، بگویید تا جابه‌جا کنم.

## آیکون سایت (favicon) و تصویر پیش‌نمایش لینک (Open Graph)

گوگل برای نمایش آیکون واقعی سایت (به‌جای آیکون خاکستری پیش‌فرض) در نتایج جست‌وجو
حداقل به یک favicon مربعی ۴۸×۴۸ پیکسل نیاز دارد؛ نسخه‌ی قبلی فقط ۳۲×۳۲ بود. الان
هر صفحه چند سایز (۳۲، ۱۹۲، ۵۱۲) به‌علاوه یک `favicon.ico` در ریشه‌ی سایت دارد.

برای تصویر پیش‌نمایش هنگام اشتراک‌گذاری لینک (واتساپ، تلگرام، توییتر و بنر گوگل)،
به‌جای عکس‌های عمودی پروژه (که در قاب افقی بد کراپ می‌شدند) دو تصویر برند‌شده‌ی
۱۲۰۰×۶۳۰ ساخته شده: `images/og-banner-group.jpg` (خانه/فلز/سرمایه‌گذاری) و
`images/og-banner-woodwork.jpg` (چوب). اگر بعداً عکس یا رنگ لوگو عوض شد، این دو
فایل هم باید دوباره ساخته شوند تا با نسخه‌ی جدید هماهنگ بمانند.

اگر لوگو یا تصاویر هیرو را عوض کردید، حتماً `favicon-*.png`، `favicon.ico` و
`og-banner-*.jpg` را هم به‌روزرسانی کنید — این‌ها به‌صورت خودکار از فایل اصلی
ساخته نمی‌شوند.

## راهنمای انتشار (Deploy)

چون همه‌ی مشتریان این سایت داخل ایران هستند، هاست را بر همین اساس انتخاب کنید:

- **Vercel را استفاده نکنید** — ترافیک ایران را رسماً مسدود می‌کند.
- **Netlify و GitHub Pages** معمولاً کار می‌کنند، اما در دوره‌های تنش منطقه‌ای ممکن
  است فیلترینگ داخلی ایران سرویس‌های خارجی را مسدود کند.
- **پیشنهاد اصلی: هاست ایرانی + دامنه‌ی .ir.** چون مخاطب صد‌درصد داخلی است، مطمئن‌ترین
  گزینه است. گزینه‌های شناخته‌شده: ParsPack / IranServer، MizbanFa، MizbanCloud —
  همه از هاست استاتیک ساده پشتیبانی می‌کنند؛ کافی‌ست کل این پوشه را با FTP یا File
  Manager کنترل‌پنل آپلود کنید (ساختار پوشه‌ها را همین‌طور نگه دارید).

ریپازیتوری گیت‌هاب (github.com/Virerra/Alborz) را برای نگهداری نسخه‌ها نگه دارید.
GitHub Pages برای پیش‌نمایش سریع مشکلی ندارد، فقط برای نسخه‌ی نهایی مشتری از هاست
ایرانی استفاده کنید.

## تست محلی

```
cd alborz-site   # یا هر اسمی که پوشه را گذاشتید
python3 -m http.server 8000
```

سپس در مرورگر: `http://localhost:8000` برای خانه‌ی گروه، `http://localhost:8000/woodwork/`
برای چوب، و به همین ترتیب برای فلز و سرمایه‌گذاری.
